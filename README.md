# Color Changer Application

A simple Android application built with Jetpack Compose for changing background colors with HEX code display.

## Description

### This application allows users to:
- Change the background color to a random color by pressing a button
- Reset the background color to white
- Display the HEX code of the current background color

### Composable Functions
- Greeting() - Displays the HEX color code
- ChangeColorButton() - Button for color changes
- getRandomColor() - Generates random colors
- getColorHex() - Converts color to HEX format

### Functionality
- Color Change: Pressing "Change Color" sets a random background
- Color Reset: Pressing "Reset to White" returns to white background
- HEX Display: Shows the HEX code of the current background color
